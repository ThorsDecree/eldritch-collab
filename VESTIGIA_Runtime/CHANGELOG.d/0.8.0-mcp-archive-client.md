## Added

- Added seven config-gated `mcp.archive.*` resident capabilities backed by the existing
  credential-minimizing local stdio MCP transport.
- Added verified MCP image reads into the resident's private content-addressed image shelf,
  preserving Archive provenance without copying base64 into prompts or receipts.

## Security

- MCP tool dispatch uses a fixed read-only allowlist rather than arbitrary passthrough.
- Runtime, provider, Discord, and tunnel credentials are not forwarded to the MCP child.
- Archive media bytes must match MCP-provided SHA-256 metadata before private import.
