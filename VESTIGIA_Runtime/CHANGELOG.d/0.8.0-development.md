# 0.8.0.dev0 — Unreleased

This fragment establishes the v0.8 development boundary after the stable v0.7.0 release.

- Move package and runtime metadata from `0.7.0` to `0.8.0.dev0` so materially different post-release wheels no longer reuse the stable public version.
- Rename CI artifacts and imported-version assertions for the development line.
- Keep the genuine v0.6.1 historical-home canary, but verify migration into the current development runtime rather than claiming another v0.7.0 artifact.
- Replace import-time private-method patch chains with explicit, ordered, collision-checked composition registries for capabilities, Observatory panels, runtime hooks, drawer modes, and contract contributions.
- Keep package import side-effect free, freeze the composition plan after startup registration, and expose that plan through diagnostics.
- Add an inert resident script shelf for immutable private source, provenance, static inspection, quarantine, archive, and typed contract records.
- Expose no provider-reachable script test, approval, activation, or execution path while hardened isolation and a separately authenticated operator approval channel are unavailable.
- Make script version allocation and lifecycle evidence/state transitions transactional and compare-and-set.
- Add a resident-private, read-only Workshop Microscope for lifecycle, provenance, contract, quarantine, and immutable-version comparison evidence.
- Register the Microscope through explicit composition and report effective script callability as false while hardened execution remains unavailable.
- Add falsifiable bookmark/cursor navigation: exact saved chunks outrank heading search, heading/chunk disagreement fails closed, cursor-only bookmarks resume their cursor instead of silently reopening chunk zero, and the established `read(bookmark_id=...)` shortcut converges on the same resolver.
- Add compact navigation proof to read/resume results and receipts, including requested and resolved position, returned chunk range, source/new cursor lineage, bookmark mutation status, source hash, and mechanically obvious next-step guidance.
- Hash-bind newly created document bookmarks and reading cursors to their verified source while keeping older durable bookmarks usable with an explicit legacy-unbound warning; unverifiable legacy cursors fail with a bounded reopen route rather than being guessed forward.
- Preserve the established cursor lifecycle exception contracts under navigation hardening: unknown/closed cursors remain `HouseCursorError` (`KeyError` family) and expired cursors remain `HouseCursorExpiredError`, while new provenance/mismatch/ambiguity failures use the navigation-specific error family.
- Refresh the current-main operator documentation: replace the stale v0.3 beginner install path, add a checked-in secret-free `.env.example`, document exact `.env`/`--env-file` precedence and current-working-directory behavior, add OpenAI and local OpenAI-compatible/Ollama provider guidance, separate local CLI bring-up from optional Discord setup, and make README version/status wording match `0.8.0.dev0` development main.
- Make the missing `OPENAI_API_KEY` diagnostic explicitly point to process environment, `--env-file`, and current-working-directory `.env`/`.env.local` discovery instead of implying one universal local `.env` path.
- Add bootstrap, collision, drawer delegation, shelf inertness, rollback, tamper, digest-conflict, lifecycle, Microscope read-only, navigation-state, and cursor-compatibility regression tests.

Before a stable v0.8.0 release, fold this fragment into `CHANGELOG.md` with the final release date and validated feature inventory.
